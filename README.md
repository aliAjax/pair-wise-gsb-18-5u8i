# 牙体牙髓病例复核台

牙体牙髓科带教用：住院医师登记根管病例并提交结案，主诊医生在复核台逐例审批，未通过病例不计入完成统计。

## 技术栈

React + Vite + TypeScript + CSS（无额外依赖，数据存于浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 功能

- **病例登记**：患者代号、牙位（FDI）、根管数、逐根管工作长度/主尖锉号/器械清点、阶段、备注
- **结案复核规则**：提交结案时自动检查记录是否齐全（基本信息、根管数一致、工作长度范围、主尖锉号、器械清点、阶段），不齐全则拦截提交
- **复核台**：主诊医生可通过或退回（退回必填原因）；学员按原因补齐后提交，自动生成新版本，旧版本与旧审批结果在版本历史中留痕可查
- **完成统计**：仅审批通过的病例计入完成；含阶段分布与学员完成情况
- **角色切换**：住院医师 / 主诊医生视角

## 目录结构

```
src/
  data/     病例资料（类型定义 types.ts、示例病例 seed.ts）
  rules/    复核规则（reviewRules.ts）
  storage/  浏览器存储（caseStore.ts，localStorage）
  pages/    页面（登记 RegisterPage、复核台 ReviewPage、统计 StatsPage）
```
